\# DevOps Pipeline Demo



A simple Node.js web application for a college DevOps practical.



\## Application



The app serves a web page at `http://localhost:3000`.



\## Run locally



```powershell

npm start```



\## Run tests



```powershell

npm test```



\## Pipeline plan



1\. Store the source code in GitHub.

2\. Use Jenkins to build and test the application.

3\. Build a Docker image.

4\. Deploy the image to Kubernetes.

5\. Verify the running application.
